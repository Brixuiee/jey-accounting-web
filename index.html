⚡ Quick Entry / 빠른 입력

한 곳에 자유롭게 적어주세요 — 시스템이 알아서 분류합니다

한 줄에 한 거래씩 자유롭게 적기만 하면 자동으로 유형(매출/수령/매입/지급/경비) · 일자 · 금액 · 거래처 · 계정과목 · 품번을 추출합니다. 이후 Preview 화면에서 관리자가 모든 항목을 수정한 뒤 Confirm 누르면 정식 등록되고, 등록 후에도 일반 메뉴(Sales Invoices, Receipts 등)에서 수정 가능합니다.

💡 각 행을 빈 칸으로 두면 자동 추정합니다. 거래처/메모 칸에 키워드를 입력하면 구분·계정과목도 자동 제안됩니다.

🏦 Bank Statement / 은행 명세서

은행 명세서를 한 곳에서 처리

은행에서 받은 CSV 또는 PDF 명세서를 업로드하면 시스템이 각 라인을 자동 분류 → Receipt/Payment/비용분개로 일괄 등록. 이미 입력된 거래는 자동 매칭되어 중복 방지. 잔액 대조도 자동. 세부 계정을 아직 모르면 "⚡ 전부 미분류로 즉시 기표"로 은행 잔액만 먼저 맞춰두고, "미분류 은행거래" 메뉴에서 나중에 하나씩 정리할 수도 있습니다.

📖 지원하는 CSV 형식

헤더 행에 다음 컬럼이 있으면 자동 인식 (대소문자 무관):

  • Date — Date / Tarikh / Transaction Date / Value Date
  • Description — Description / Particulars / Narration / Remarks
  • Withdrawal (출금) — Withdrawal / Debit / DR / Out
  • Deposit (입금) — Deposit / Credit / CR / In
  • Balance (선택) — Balance / Baki / Running Balance
  • Reference (선택) — Ref No / Cheque No / Transaction Ref

지원 은행: Maybank, CIMB, Public Bank, RHB, Hong Leong, AmBank 등 — 표준 CSV export 호환. 출금/입금이 한 컬럼(Amount)으로 합쳐진 경우(음수=출금) 자동 인식.

Import from Mr. Accounting (MySoft)

Import data exported from MySoft Mr. Accounting. Supported formats: CSV, Excel (.xlsx/.xls), PDF, Word (.docx). Select the data type, then upload the file.

Import Notes

  • Supported file formats: CSV, Excel (.xlsx/.xls/.xlsm), PDF, Word (.docx). Legacy .doc binary files must be re-saved as .docx or .csv.
  • Excel: only the first sheet with data is imported. Row 1 must be the header row.
  • PDF: text-based PDFs only (scanned/image PDFs need OCR first). Columns are recovered from horizontal spacing — tables export best.
  • Word (.docx): if the document contains a table, it is imported directly; otherwise rows are recovered from multi-space-separated text.
  • GL Transactions file must have columns: Date, Reference, Description, Account Code, Debit, Credit (header row required)
  • Chart of Accounts CSV must have columns: Account Code, Account Name, Type — Type values: Asset, Liability, Equity, Revenue, Expense
  • Customers CSV must have columns: Code, Name, Contact Person, Phone, Email, Credit Limit
  • Suppliers CSV must have columns: Code, Name, Contact Person, Phone, Email, Payment Terms
  • All amounts must be numeric without currency symbols or commas
  • Dates must be in YYYY-MM-DD or DD/MM/YYYY format
  • Import will not duplicate accounts — existing account codes are matched
  • After import, review the Trial Balance to verify data integrity
